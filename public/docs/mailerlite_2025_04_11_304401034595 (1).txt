 Astro uses a system called "style scoping" which automatically isolates component styles to prevent conflicts. 
 Here's how you can adapt your code: 
 1. Create an Astro component file (e.g., src/components/MailerLiteForm.astro). 
2. Move the HTML structure from the <body> of your original code into the template section of your Astro component. 
3. Move the CSS from the <style> tags into a <style> tag within your Astro component. Astro will automatically scope these styles. 
4. Keep the external CSS import and the JavaScript includes in the <head> of your main layout or within the <head> section of your Astro component if you only intend to use the form on specific pages.
