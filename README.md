# Religious Freedom Indiana Website

This is the website for rfindiana.org.

## Documentation

For detailed setup and implementation instructions, refer to the `docs/` folder. Key documents include:

- `docs/brevo-instructions.md`: Instructions for integrating Brevo for email newsletters.
- `docs/architecture.md`: Overview of the site's architecture.
- `docs/roadmap.md`: Development roadmap and milestones.

## Getting Started

To contribute or run the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to view the site.
